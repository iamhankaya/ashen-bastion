# v2.0.3 cihaz doğrulama — faz D (ana sayfa + ayarlar)

Bu bölüm dosyasını yalnız ilgili faz doldurur; ortak `docs/dev/user-verify.md` birleştirmesini doğrulama fazı yapar (N4).

Cihaz: Redmi Note 13 Pro (debug APK).

1. **Ana sayfa akıcılığı:** menüde kül/kor, sancak sallanması ve karakter nefesi takılmadan çalışır (60 fps hissi). Beklenen: kasma yok.
2. **Çentik/alt çubuk:** başlık çentiğin altında, düğme sütunu alt çubuğun üstünde; AYARLAR ve EN İYİ SKORLAR kesilmiyor.
3. **AYARLAR → SES:** TÜM SESLER kapatınca "Ses kapalı…" satırı çıkar, kaydırıcı soluk; bir kaydırıcıya dokununca ses açılır. MÜZİK/EFEKT bırakınca kaydedilir (uygulamayı kapatıp aç).
4. **Kaydırırken kazara tetik:** AYARLAR listesini parmakla kaydırırken anahtarlar tetiklenmemeli (24 px eşiği uygulanmadı; sorun görülürse bildir). Kaydırıcıyı sürüklerken liste kaymamalı.
5. **HAREKETİ AZALT AÇIK:** ana sayfada kül/kor görünmez, sancak/meşale/nefes durur; KAPALI yapınca geri gelir.
6. **TİTREŞİM:** AÇIK/KAPALI; doldurma/vuruşta titreşim ayara uyar (eski ana sayfa anahtarının yeri artık yalnız AYARLAR).
7. **Duraklatmadan AYARLAR:** aynı ekran açılır, GERİ duraklatmaya döner.

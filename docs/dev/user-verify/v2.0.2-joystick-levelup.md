## Seviye atlama sonrası joystick (T20261025-82) — cihaz kontrolü

- [ ] Seviye atlama ekranında beceri kartına dokun, **parmağı kaldırmadan** kilit süresi (0,6 sn) boyunca ekranda basılı tut: kilit bitince joystick hemen belirir, parmağı sürükleyince karakter hemen yürür; yön takılı kalmaz.
- [ ] Aynı senaryo, kartı seçtikten sonra parmağı kaldırıp **yeniden bas**: ilk dokunuşta joystick tepki verir.
- [ ] Çoklu dokunuş: bir parmak kartta, diğeri oyun alanında (kilit sırasında bas): kilit bitince ikinci parmak joystick'i sürer, kart parmağı etkilemez.
- [ ] Duraklat → Devam sonrası aynı iki senaryo (aynı kilit yolunu kullanır).
- [ ] Öldürülene kadar tekrar eden seviye atlamalarında (3–4 kez art arda) hiçbirinde "takılı yön" yok.
